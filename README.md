# Nelyx Engine
Nelyx Engine is a Work-in-progress fork of Woof! made for Project Apocrypha and Super Tux Doom

# Why does the Nelyx Engine even exist?
In December 23 1997, **John Carmack released the source code of the [Doom engine](https://github.com/id-software/doom), known as Linux Doom** that was one of the most optimized engines for it's time, that meant **anyone could study, modify, compile and fork the Doom engine under a non-commercial license.**
On October 3rd, 1999, **the code got a re-release under the General Public License 2.0**, and now **anyone could make a commercial game in the Doom engine**, and that's where Id Software's part ends on this story. Thank you for everything, Id!
